# 리뷰 체크리스트

자체 리뷰(`prompts/40-review.md`)와 사람 리뷰가 함께 쓰는 기준이다.
각 항목은 대조할 대상과 근거 위치만 적는다. 판단 기준은 근거 문서에 있다.

## 판정

- `통과`: 근거(파일·라인, 실행한 명령과 결과)를 함께 적는다.
- `미통과`: 위치와 이유를 적는다.
- `해당 없음`: 이유를 적는다.
- `미확인`: 확인하지 못한 항목이다. 통과로 바꾸지 않는다.
- A·H·I·J·K·M은 항상 적용한다. 나머지는 해당 변경이 있을 때 적용한다.
